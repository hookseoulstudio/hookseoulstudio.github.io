VocaQueen 개인정보처리방침

운영자: Hookseoul Studio · 시행일: 2026년 11월 6일

Hookseoul Studio는 한국어 사용자를 위한 CEFR 영어 단어 학습 앱 ‘VocaQueen’(Android 패키지: com.vocaqueen.app)을 제공합니다. 이 방침은 현재 앱에서 처리하는 정보와 이용자의 선택 사항을 설명합니다.

1. 앱에서 처리하는 정보

앱은 계정 가입이나 로그인을 제공하지 않으며, 이메일·전화번호·위치·연락처·사진·카메라·마이크 정보를 요청하지 않습니다. 다음 정보는 앱을 사용하는 동안 기기 내부에 저장됩니다.

  • 이름: 프로필에 직접 입력한 경우에만 저장합니다(선택, 최대 24자).
  • 학습 정보: 선택한 학습 레벨, 배치 테스트 결과, 단어별 학습 상태와 복습 일정, 학습 위치, 즐겨찾기 단어, 연속 학습 기록, 프로필을 만든 시각
  • 테스트 기록: 테스트 점수와 응시 내역(최근 최대 200회)
  • 앱 설정: 언어, 화면 테마, 발음 사용 여부, 하루 학습 목표, 테스트 문항 수, 학습 카드 표시 항목

앱은 이 정보를 Hookseoul Studio의 서버나 다른 제3자에게 전송하지 않습니다. 단어 데이터는 앱에 포함되어 있어, 학습에 인터넷 연결이 필요하지 않습니다.

2. 이용 목적

이름은 앱 화면에 표시하는 데 사용합니다. 학습 정보와 테스트 기록은 학습·복습 진행과 통계를 보여주는 데 사용하고, 설정은 앱 화면과 학습 방식을 맞추는 데 사용합니다.

3. 제3자 제공, 위탁 및 국외 이전

Hookseoul Studio는 위 정보를 받지 않으므로 제3자에게 제공하거나, 처리를 위탁하거나, 국외로 이전하지 않습니다. 현재 앱에는 광고, 행동 분석, 오류 보고 또는 사용자 계정용 SDK가 없습니다.

다음은 이용자의 기기와 계정 설정 또는 이용자의 선택에 따라 다른 사업자가 처리할 수 있는 경우입니다.

  • Android 백업: 기기의 백업 설정에 따라 앱 정보가 이용자의 Google 계정에 백업·복원될 수 있습니다. 이 처리에는 Google의 개인정보처리방침이 적용되며, Hookseoul Studio는 해당 백업에 접근하지 않습니다.
  • 발음 듣기: 발음은 기기에 설정된 음성 합성 엔진으로 재생하며, 앱은 재생할 단어를 그 엔진에 전달합니다. 앱은 음성 파일을 내려받거나 단어를 Hookseoul Studio의 서버로 보내지 않습니다. 음성 엔진의 처리 방식은 해당 엔진 제공자의 방침을 따릅니다.
  • 외부 링크: 앱의 라이선스 화면에서 데이터 출처 링크를 누르면 해당 웹사이트로 이동하며, 그 사이트의 방침이 적용됩니다.

4. 학습 기록 내보내기

설정에서 내보내기를 실행하면 이름, 학습 정보, 테스트 기록, 설정이 담긴 파일을 이용자가 고른 위치에 저장합니다. 앱은 이용자가 직접 실행할 때만 이 파일을 만들며, Hookseoul Studio로 보내지 않습니다. 파일은 암호화되지 않으므로 다른 사람과 공유하지 않도록 주의해 주세요. 클라우드 저장소 등을 저장 위치로 고르면 해당 서비스의 방침이 적용됩니다.

5. 보관 및 삭제

기기에 저장된 정보는 이용자가 삭제하거나 앱을 제거할 때까지 보관합니다. 테스트 기록은 최근 200회까지만 남고 오래된 기록은 자동으로 삭제됩니다. 정보를 삭제하는 방법은 다음과 같습니다.

  • 학습 기록 초기화: 설정에서 학습 위치, 테스트 기록, 단어별 학습 상태, 연속 학습 기록을 삭제할 수 있습니다. 이름, 즐겨찾기 단어, 선택한 레벨, 배치 테스트 결과, 설정은 이때 삭제되지 않습니다.
  • 이름과 즐겨찾기: 프로필에서 이름을 바꾸거나 지울 수 있고, 즐겨찾기는 단어별로 해제할 수 있습니다.
  • 전체 삭제: Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 기기에 저장된 정보가 모두 삭제됩니다.

내보낸 파일은 이용자가 직접 삭제해야 하며, Android 백업 사본은 이용자의 Google 계정 백업 설정에 따라 별도로 관리될 수 있습니다. Hookseoul Studio는 이 정보를 자체 서버에 보관하지 않으므로 서버 측에서 삭제할 계정이나 기록은 없습니다.

6. 이용자의 권리

이용자는 앱에서 자신의 정보를 열람하고, 위 방법으로 수정하거나 삭제할 수 있습니다. Hookseoul Studio는 이 정보를 보유하지 않으므로 Hookseoul Studio가 대신 열람하거나 삭제할 수는 없습니다. 궁금한 점이나 요청 사항은 아래 문의처로 보내주세요.

7. 보안 및 외부 서비스

앱의 정보는 Android의 앱별 저장 영역에서 관리됩니다. 기기 자체의 잠금과 운영체제 보안 설정은 이용자가 관리할 수 있습니다. Google Play를 통한 앱 설치·업데이트 과정에서 Google이 처리하는 정보에는 Google의 개인정보처리방침이 적용됩니다.

이 방침을 게시하는 GitHub Pages 웹사이트에 접속할 때에는 GitHub가 웹 접속 정보를 처리할 수 있으며, 그 처리에는 GitHub의 개인정보처리방침이 적용됩니다. 이는 앱의 학습 기록과 별개입니다.

8. 변경 안내

향후 광고, 온라인 계정, 분석 또는 서버 기능을 추가하여 정보 처리 방식이 달라지는 경우, 해당 기능을 제공하기 전에 이 방침과 Google Play 데이터 보안 정보를 실제 동작에 맞게 수정하겠습니다.
